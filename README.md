## 👨‍💻 About Me

I'm an **Electrical Engineer and Software Engineer** passionate about building robust backend systems, cloud-native applications, and intelligent engineering solutions.

My background in electrical engineering shapes how I approach software: I enjoy understanding systems from the ground up, solving complex problems, and designing solutions that are efficient, reliable, and scalable.

- ⚙️ **Backend:** Java, Spring Boot, C++, and Drogon.
- 🌐 **Frontend:** Angular and modern web technologies.
- ☁️ **Cloud & DevOps:** Cloud infrastructure, containerization, automation, and deployment pipelines.
- 🗄️ **Databases:** PostgreSQL, MySQL, SQL, and MongoDB.
- 🤖 **Side interests:** Data science, machine learning, Python, and MATLAB.
- ⚡ **Engineering foundation:** Electrical systems, automation, and control engineering.
- 🎯 **Goal:** Build production-ready software that solves real-world problems.
